# ACM 训练助手设计文档

## 目标

构建一个 Windows 本地桌面应用，帮助用户管理 ACM 训练、VP 比赛、赛后复盘、图片激励墙和比赛提醒。应用需要在后台常驻，支持开机自启、托盘操作、电脑解锁后的提醒弹窗，以及断网时的本地可用性。

第一版目标是做出 MVP 可用版：核心功能全部打通，界面保持简洁，不做复杂训练计划、多设备同步或团队协作。

## 技术方向

应用采用 Electron + React + TypeScript 实现，作为 Windows 本地桌面应用运行。

核心技术选择：

- Electron 负责桌面壳、系统托盘、开机自启、Windows 通知、置顶窗口和后台常驻。
- React + TypeScript 负责主界面、列表、筛选、表单、详情页和图片墙。
- SQLite 负责本地结构化数据存储。
- 本地文件夹负责保存导入的图片文件。
- 后台任务负责联网刷新比赛提醒缓存，并在解锁或手动刷新时触发更新。

Node 环境可以在实施阶段配置。当前项目不依赖云端服务，所有核心数据保存在本机。

## 产品形态

应用是一个常驻托盘的 Windows 桌面助手。

行为要求：

- 开机自动启动。
- 主窗口关闭后仍可留在后台。
- 托盘菜单提供打开主窗口、打开计时器、刷新比赛、查看今日提醒和退出应用。
- 用户可以手动退出后台进程。
- 数据全部本地保存，断网时仍能打开、查询、浏览图片和查看缓存比赛。

第一屏是“今日面板”，视觉风格为安静效率型，加入少量 ACM 训练压迫感。日常界面保持清爽；比赛标签、倒计时、银牌/金牌/翻车等标签可以更醒目。

## 主模块

### 今日面板

今日面板是主窗口首页。

展示内容：

- 今天日期、联网状态和比赛缓存更新时间。
- 今日 Codeforces、AtCoder、牛客比赛。
- 今天或近期计划 VP 的比赛。
- 计时器入口。
- 今日随机图片提醒。

今日面板不做复杂训练计划，只聚合当天最需要看的信息。

### 比赛提醒

比赛提醒覆盖 Codeforces、AtCoder 和牛客系列赛。

数据来源：

- Codeforces 使用官方 contest.list API。
- AtCoder 从官方 contests 页面或可用列表源获取 upcoming contests。
- 牛客只自动抓取周赛、月赛和挑战赛。
- 牛客寒暑假训练营、报名制比赛和其他临时比赛由用户手动添加。

抓取结果写入本地缓存。网络失败时不阻塞使用，只显示本地缓存和上次更新时间。

提醒策略：

- 应用启动后检查今天是否已经提醒过。
- Windows 解锁后延迟几秒尝试联网刷新，再生成今日提醒。
- 用户可以从主界面或托盘手动刷新比赛。
- 如果今天有比赛，先发 Windows 系统通知，再弹出可关闭的今日提醒小窗口。
- 自动提醒每天只弹一次；用户可以手动再次打开。

### VP 比赛库

VP 比赛库用于管理用户想 VP 或已经 VP 的比赛。

VP 记录字段：

- 平台
- 比赛名
- 链接
- 用户自己选择的 VP 日期时间
- 备注
- 状态

日期表示用户自己计划或实际 VP 的时间，不从网页自动读取。日期输入使用固定格式的日期时间选择控件，便于按年、月、日筛选。

添加比赛时，用户粘贴链接后，系统尝试识别平台和标题。第一版支持尝试识别：

- Codeforces
- AtCoder
- 牛客
- QOJ
- 洛谷
- 计蒜客
- VJudge
- HDU

自动识别失败时不能阻止保存。系统应保留链接，并允许用户手动编辑平台、标题和日期。

VP 比赛库支持增删改查，支持按平台、年月和关键词筛选。

### VP 复盘

复盘是独立模块，不直接混进 VP 基本信息里。

一场 VP 可以关联多条复盘，用于记录不同阶段的总结，例如第一次 VP、补题总结、二刷复盘。

复盘字段：

- 关联 VP
- 标题
- 正文
- 成绩标签
- 自由标签
- 创建时间
- 更新时间

成绩标签可包含银牌、金牌、铜牌、翻车、补题完成等。自由标签用于记录 DP、图论、构造、罚时、读题失误等自定义分类。

复盘列表支持按标签、关键词、平台和年月筛选。

### 图片墙

图片墙是本地图片收藏和激励模块。

第一版只支持图片，不做 PDF、链接库或复杂资料库。

功能要求：

- 支持拖入图片或选择图片导入。
- 导入时复制图片到应用数据目录。
- 支持标题、标签和导入日期。
- 支持标记“允许随机提醒”。
- 图片墙页面支持浏览和按标签筛选。

每天第一次解锁时，如果图片随机提醒开启，系统从允许提醒的图片中随机抽一张，在今日提醒窗口中展示。首页也可以展示同一张今日随机图片。

### 置顶计时器

计时器是独立小窗，不绑定复杂训练计划。

功能要求：

- 支持正计时。
- 支持倒计时。
- 支持始终置顶。
- 支持开始、暂停、重置。
- 倒计时结束时发系统通知，并在小窗中显示明显提示。

计时器可以从主窗口今日面板或托盘菜单打开。

## 数据存储

使用 SQLite 保存结构化数据，使用本地文件夹保存图片。

建议应用数据目录：

- SQLite: Windows 用户应用数据目录下的应用数据库文件。
- 图片: 应用数据目录下的 media/images。
- 比赛缓存: SQLite 表中保存，并记录来源和更新时间。

核心表或实体：

- ContestReminderCache
- VpContest
- VpReview
- ReviewTag
- ImageWallItem
- AppSettings
- DailyReminderState
- TimerState

关键关系：

- 一个 VpContest 可以关联多条 VpReview。
- VpReview 可以有多个标签。
- ImageWallItem 可以有多个标签，并可单独控制是否参与随机提醒。
- DailyReminderState 记录某天是否已经自动提醒，避免重复弹窗。

## UI 结构

主窗口采用左侧导航 + 内容区布局。

左侧导航：

- 今日
- 比赛提醒
- VP 比赛
- 复盘
- 图片墙
- 设置

设置页 MVP 只放必要项：

- 开机自启开关
- 今日比赛提醒开关
- 图片随机提醒开关
- 手动刷新比赛按钮
- 数据目录展示
- 退出后台应用

第一版避免复杂设置和过度视觉装饰，优先保证每天打开就能使用。

## MVP 范围

第一版包含：

- Electron 桌面应用基础架构。
- 开机自启和托盘常驻。
- 今日面板。
- Codeforces、AtCoder、牛客周赛/月赛/挑战赛比赛提醒缓存。
- 启动、解锁和手动刷新后的今日提醒。
- VP 比赛增删改查。
- 链接识别与手动兜底。
- 一场 VP 多条复盘。
- 复盘标签和搜索筛选。
- 图片墙导入、浏览、标签和每日随机提醒。
- 置顶正计时/倒计时小窗。
- 本地 SQLite 和图片文件存储。

第一版不包含：

- 多设备同步。
- 团队协作。
- 自动读取用户 VP 日期。
- PDF 或复杂资料库。
- 固定时间学习提醒。
- 复杂训练计划系统。
- 牛客全站比赛抓取。
- 完整视觉主题系统。

## 风险与处理

### Node 环境

当前机器 Node 被系统拒绝运行，实施阶段需要配置可用 Node 环境。优先修复或安装 Node LTS。

### 平台抓取稳定性

不同平台页面可能改版。设计上必须允许抓取失败，并提供手动编辑兜底。添加 VP 链接时，保存链接本身优先于自动识别成功。

### 离线场景

用户晚上可能无网络。所有提醒数据必须缓存，应用启动和查询不能依赖实时联网。网络失败时显示缓存状态，而不是报错阻断。

### 提醒打扰

自动弹窗每天只弹一次。系统通知和提醒窗口都应可关闭。用户可以在设置中关闭今日比赛提醒和图片随机提醒。

## 验收标准

- 应用能在 Windows 上启动，并显示今日面板。
- 关闭主窗口后应用仍在托盘常驻，托盘可以重新打开主窗口。
- 用户可以配置开机自启。
- 联网时能刷新 Codeforces、AtCoder 和牛客系列赛比赛缓存。
- 断网时仍能查看上次缓存和本地 VP/复盘/图片数据。
- 每天第一次解锁时，应用能根据缓存和设置弹出今日提醒。
- 用户可以新增、编辑、删除和搜索 VP 比赛。
- 用户粘贴支持平台链接时，系统尝试自动填充标题和平台；失败时仍可保存并手动编辑。
- 一场 VP 可以添加多条复盘，并能按标签或关键词检索。
- 用户可以导入图片到图片墙，并让图片参与每日随机提醒。
- 计时器支持正计时、倒计时和始终置顶。
